## Mission 4 : Comparatif d'outils

Les choix effectués pour ce projet sont les suivants :
* **Ruff** (Linter/Formatter) : Choisi pour sa rapidité extrême.
* **Mypy** (Type Checker) : Utilisé pour vérifier la cohérence des types de données.
* **Pytest** (Tests) : Framework flexible pour valider la logique de prédiction.
* **Bandit & Safety** (Sécurité) : Retenus pour détecter les vulnérabilités dans le code et les dépendances.
